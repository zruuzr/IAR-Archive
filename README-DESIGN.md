## 1. الفلسفة المعمارية (Design Philosophy)

يقوم نظام تصميم **دار الحكمة المعاصرة (Modern Bayt al-Hikma Editorial)** على دمج عمق التاريخ المعرفي الرافديني العريق بأعلى معايير الدقة الهندسية والتحريرية الرقمية المعاصرة:

1. **الأصالة الرافدينية (Mesopotamian Heritage):**
   استلهام الأختام السومرية والرموز المسمارية (`U+12000–U+123FF`) والنقوش الهندسية الطينية المذهبة دون بهرجة زائدة أو كليشيهات سطحية.
2. **الوقار الأكاديمي (Editorial Prestige):**
   مظهر أرشيفي ملكي مستوحى من كبرى الدور الأكاديمية والمكتبات العالمية (بياض مُريح، تباين لوني دقيق، وفواصل رصينة).
3. **الدقة الوظيفية (Functional Precision):**
   السرعة الفائقة، والتنقل السلس عبر Vanilla JS Modules، وتوافق تام مع معايير الوصول العالمية **WCAG 2.1 AA**.

## 3. الخطوط والطباعة (Typography)

التزام صارم بالخطوط المعتمدة حصراً في المشروع:
- **IBM Plex Sans Arabic (300, 400, 500, 600, 700):** الخط الأساسي لجميع النصوص والعناوين والبطاقات.
- **Noto Sans Cuneiform:** لعرض الرموز المسمارية التاريخية (مثل `𒆠𒂗𒂠`, `𒀭𒈗𒂗𒆠`).

```css
--font-sans: 'IBM Plex Sans Arabic', system-ui, -apple-system, sans-serif;
--font-cuneiform: 'Noto Sans Cuneiform', serif;
```

## 4. المكونات المعمارية الرئيسية (Key Components)

### أ. شريط التراث الحي (Mesopotamian Archival Ticker)
شريط علوي دقيق يعرض الشعار بالرمز المسماري والخط العربي واللاتيني بنبض حيوي.

### ب. الترويسة الأرشيفية (Sovereign Site Header)
- قفل الشعار (Brand Lockup): ختم سومري ذهبي هندسي بجانب عنوان المؤسسة الأكاديمي.
- مقاييس الأرشيف الحية (Live Counter Badges): عداد المراجع، التصنيفات، الزيارات، سنة الأرشفة.
- أدوات التحكم العلوية: زر تبديل اللغة (AR/EN)، زر المظهر (داكن/فاتح)، وزر تثبيت التطبيق (PWA).

### ج. لوحة الصدارة في دائرة الضوء (Featured Spotlight)
عرض أفقي رحب للمرجع الموصى به مع غلاف تجليد فاخر وأزرار تفاعلية فورية (ملخص 3 دقائق، توثيق APA، قراءة، تحميل، مشاركة).

### د. منصات العرض المتحفية (Exhibition Plinths & 3D Codex Cards)
- بطاقات مراجع ثلاثية الأبعاد بملامح المخطوطات والكتب المجلدة فاخرة التجليد.
- واجهة جلدية زخرفية عند غياب الغلاف المصور بخمس نغمات أرشيفية راقية.
- ختم المسمارية الذهبي المدمج مع سنة الإصدار.

### هـ. رصيف الحزم البحثية العائم (Floating Research Bundles Dock)
شريط عائم زجاجي مع مؤشر حي للمراجع المختارة، مع إمكانية نسخ رابط حزمة مشارك فوراً أو إلغائها بنقرة واحدة.

### و. قارئ PDF ومودال ملخص الـ 3 دقائق (Modals & Reader)
- نافذة حوارية منبثقة متوافقة مع إمكانية الوصول تعرض الأفكار الرئيسية، الفئة المستهدفة، وتوثيق APA المباشر.
- قارئ PDF مدمج عبر Mozilla PDF.js.

## 5. هيكلية البرمجيات (JavaScript Architecture)

تمت إعادة هيكلة الكود إلى 4 طبقات محكمة ضمن `js/`:

```
js/
├── core/             # النواة الأساسية
│   ├── utils.js      # الأدوات العامة وعمليات DOM
│   ├── state.js      # الحالة المركزية Reactive State
│   ├── i18n.js       # الترجمة ودعم اللغتين والأرقام
│   └── router.js     # التوجيه وإدارة الـ URL والتاريخ
├── data/             # طبقة البيانات
│   ├── data.js       # معالجة وتحليل المراجع
│   ├── data-fetch.js # جلب البيانات ومزامنة الإحصاءات
│   └── firebase.js   # تكامل Firestore والمصادقة
├── ui/               # مكونات الواجهة
│   ├── ui-helpers.js # الإشعارات والمودال والمشاركة
│   ├── ui-init.js    # إعداد الواجهة والسمة واللغة
│   └── render.js     # رسم البطاقات والصفحات والتصنيفات
└── features/         # الميزات التفاعلية
    ├── download.js   # التحميل المتقدم وحلقة التقدم
    ├── ratings.js    # التقييم التفاعلي بالنجوم
    ├── pwa.js        # إدارة تثبيت تطبيق الويب التقدمي
    └── events.js     # ربط ومعالجة أحداث الـ DOM
```

مع الحفاظ على ملفات تجسير (Bridge modules) في المسار الأساسي `js/*.js` لتأمين التوافقية بنسبة 100% ودون أي كسر للروابط القديمة.
