# 📚 IAR-Archive (Iraqi Administrative Reference Archive)

**أرشيف العلوم الإدارية العراقي** هو منصة رقمية ومكتبة مخصصة لإتاحة المراجع، الكتب، والبحوث الأكاديمية في مجالات الإدارة والتطوير الإداري للطلاب، الباحثين، والمهنيين.

---

## 🚀 المميزات الرئيسية
* 🔍 **بحث سريع:** إمكانية البحث الفوري في قائمة الكتب والمراجع.
* ⭐️ **نظام تقييم تفاعلي:** تقييم الكتب وتخزين النتائج فورياً عبر **Firebase Cloud Firestore**.
* ⚡️ **تحميل واستعراض مباشر:** معاينة وتنزيل ملفات الـ PDF بضغطة زر.
* 📱 **تصميم متجاوب:** يعمل بكفاءة وسلاسة على الأجهزة المحمولة والحواسيب.

---
