# IAR Archive | المستودع الرقمي العراقي للمراجع الإدارية

[![Cloudflare Pages](https://img.shields.io/badge/Hosted%20on-Cloudflare%20Pages-orange?style=flat&logo=cloudflare)](https://iar-archive.pages.dev)
[![Firebase](https://img.shields.io/badge/Database-Firebase-yellow?style=flat&logo=firebase)](https://firebase.google.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**IAR Archive** هو منصة رقمية تفاعلية مخصصة لأرشفة وربط المراجع الإدارية، مصممة خصيصاً لتوفير ملخصات سريعة (3 دقائق)، التوثيق الأكاديمي المباشر بصيغة APA، وإنشاء حزم بحثية مخصصة للباحثين وطلاب الدراسات العليا والمدراء التنفيذيين.

---

## 🚀 الميزات الأساسية للمنصة

* **ملخصات 3 دقائق:** تقديم أبرز الأفكار الرئيسية والفئة المستهدفة لكل مرجع إداري لسرعة الاستيعاب.
* **التوثيق الأكاديمي (APA):** إمكانية نسخ التوثيق الأكاديمي المباشر بضغطة زر واحدة.
* **حزم البحوث المخصصة:** إمكانية تحديد مجموعة من المراجع ومشاركة رابط مخصص يضمها كحزمة بحثية متكاملة.
* **دعم ثنائي اللغة (عربي / إنجليزي):** واجهة متكاملة تدعم التبديل السلس بين اللغتين مع ضبط الاتجاه (RTL/LTR).
* **الوضع الداكن والفاتح:** دعم كامل لتغيير المظهر بحسب تفضيل المستخدم مع حفظ الإعدادات محلياً.
* **التفاعل والتقييم:** نظام تقييم جماعي للكتب ومتابعة إحصائيات التحميل والزوار الفريدين عبر Firebase.

---

## 🛠️ البنية التقنية وحديث التحديثات (Architecture)

تم تطوير المستودع ليعمل بكفاءة عالية وبشكل مجاني بالكامل عبر اعتماد البنية التقنية التالية:

* **الواجهة الأمامية (Frontend):** HTML5, CSS3, JavaScript (Vanilla)، مع إطار العمل Bootstrap 5.
* **الاستضافة والنشر (Hosting):** مُستضاف على **Cloudflare Pages** لضمان السرعة الفائقة والانتشار العالمي عبر شبكة CDN.
* **إدارة الملفات الكبيرة (Large Assets):** لتجاوز حد الـ 25 ميجابايت المفروض على ملفات الاستضافة الثابتة، تم توجيه روابط تحميل وعرض ملفات الـ PDF الكبيرة مباشرة عبر مستودع GitHub الخام (`raw.githubusercontent.com`) مع دعم كامل لترميز المسافات والأسماء الخاصة.
* **قاعدة البيانات والخدمات (Backend / Database):** استخدام **Firebase Firestore** و **Firebase Auth** لإدارة عدادات التحميل، تقييمات الكتب، وحساب الزيارات الفريدة.
* **الأتمتة (Automation):** ربط المستودع بـ **GitHub Actions** لتحديث ملف البيانات (`books.json`) وتفعيل إعادة النشر التلقائي فور إضافة أي مرجع جديد.
